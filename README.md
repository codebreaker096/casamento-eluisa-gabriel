## 🚀 Como Hospedar Gratuitamente no GitHub Pages

1. Crie um novo repositório no seu GitHub (ex: `convite-casamento`).
2. Conecte o repositório local e envie os arquivos:
   ```bash
   git remote add origin https://github.com/SEU-USUARIO/convite-casamento.git
   git branch -M main
   git push -u origin main
   ```
3. No GitHub:
   - Vá em **Settings** (Configurações) > **Pages**.
   - Em **Build and deployment > Source**, selecione **Deploy from a branch**.
   - Em **Branch**, escolha `main` e a pasta `/ (root)`.
   - Clique em **Save**.
4. Em menos de 1 minuto, o link do seu convite estará online no ar para todos os convidados! (Ex: `https://SEU-USUARIO.github.io/convite-casamento/`)
